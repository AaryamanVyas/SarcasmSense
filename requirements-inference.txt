# ===========================================================================
#  REQUIRES CPython 3.10, 3.11 or 3.12  (3.11 recommended)
#
#  On a newer interpreter (3.13+) pip finds no wheels for numpy/scipy/torch/
#  faiss, falls back to building them from source, and fails with a confusing
#  error about a missing Fortran or C++ compiler. Installing a compiler does
#  NOT fix it -- torch has no source build for those interpreters.
#
#  Check before installing:   python scripts/check_environment.py
# ===========================================================================

# ---------------------------------------------------------------------------
# PRODUCTION / INFERENCE dependencies.
#
# This is what the serving container installs. It is deliberately smaller than
# requirements-training.txt: no plotting, no dataset tooling, no test runner.
#
# CPU-only PyTorch is strongly recommended for serving. The default PyPI wheel
# for Linux bundles ~2.5 GB of CUDA libraries you do not need on a CPU box:
#
#   pip install torch==2.5.1 --index-url https://download.pytorch.org/whl/cpu
#   pip install -r requirements-inference.txt
#
# The Dockerfile does exactly that.
# ---------------------------------------------------------------------------
